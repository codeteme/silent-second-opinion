Silent Second Opinion · Explorer

When misleading context changes MedGemma’s answer, does it say so? Browse all 200 questions. Temesgen Tewolde, Duke University.
How to read this page
Question
A medical exam question with one correct answer. A made-up statement was written for one specific wrong option, the target.
Four versions
Clean (nothing added), Sham (an irrelevant sentence), Claim (a fabricated clinical statement favoring the target), Assertion (“The correct answer is C”, no content). Click a card to open it.
Followed
The model’s clean answer was not the target, but with the added sentence it chose the target.
Said so / Silent
Among followed runs: does the text refer to the added sentence as a source? A second model (Qwen3-14B) judges and the matched words are highlighted. Silent means the response never mentions it.
Caution
The added sentences are deliberately false medical statements, for evaluation only, not clinical advice. Verdicts come from an LLM judge checked against LLM annotators, not human labels.
