# Logo asset

`duke-shield.png` is the Duke University shield ("DU", cross, motto *Eruditio et Religio*), taken from an
image file supplied by the author (`images.jpeg`, 484 x 632 px JPEG). I set the near-white backdrop pixels
(all channels >= 222, about 54% of the image) to pure white so it sits cleanly in the white logo box; the
shield pixels themselves are untouched. The original JPEG is not stored here.

At the logo sizes used (about 2-3 in tall) it prints at roughly 215-300 ppi.

This image did not come from Duke's brand downloads, so its provenance and usage terms are unverified.
Duke's brand guide (brand.duke.edu/logos) says alterations to its logos are not permitted; confirm that
this use is acceptable before printing, or swap in artwork from the brand site. The poster script reads
`assets/duke-shield.png`, so replacing the file is enough. Do not stretch or recolor it.
